### Walk All SF Roads

demo video:

https://github.com/user-attachments/assets/b46bb620-ed26-44de-a26c-777d64dc9b32


I have a personal goal to walk all the streets in San Francisco. Since I know Python and I like doing things myself I decided to write code to motivate me and keep me accountable during this project. This project uses open source software to compare real GPS traces from my phone to OSM data to determine which streets have been walked (yellow), or completed (green), all with a temporal dimension that you can watch as an animation of the streedt grid changing colors as you walk them.
